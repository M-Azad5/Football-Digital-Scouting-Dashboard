# ScoutPro Analytics Dashboard

## Overview
ScoutPro is a football analytics dashboard built using Streamlit. It allows users to explore player performance through interactive visualisations.

## Features
- User authentication 
- Player filtering 
- Interactive charts 
- Player search functionality
- CSV download of filtered data

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## How to Run Locally
pip install -r requirements.txt
streamlit run app.py
